The ReAct loop

How an agent reasons and acts — and why it was a breakthrough in 2022.

Step 1 of 5

ReAct (Reasoning + Acting) was introduced in a 2022 paper and gave agents something they'd been missing: explicit reasoning steps interleaved with tool calls. Instead of jumping straight to an action, the model first writes out its thinking — which dramatically improved reliability and made agent behaviour interpretable.

Before doing anything, the model writes a "Thought" — its reasoning about what it knows, what it needs, and what to do next. This step is the key innovation: it gives the model a scratchpad to plan, which reduces errors and lets you see exactly why it chose each action.

The Action is the tool call — chosen directly from the reasoning in the Thought step. Notice how both the thinking and the action are written into the context window. This is what makes the trace readable: you can follow exactly how the model got from the user's question to each tool call.

The Observation is just the tool result, appended to the context. The model reads it and makes a decision: does it have enough to answer, or does it need to think and act again? This is the loop — it continues until the model decides it's done, then writes a final answer.

A complete ReAct trace: two Thought–Action–Observation loops before a final answer. Every step is visible in the context window — you can read exactly how the agent reasoned its way to the answer. This interpretability was a big part of why ReAct was influential: for the first time, you could audit an agent's reasoning, not just its output.
