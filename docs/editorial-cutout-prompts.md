# Editorial cutouts

These derivatives use the built-in imagegen tool to remove poster lettering and the paper background for the home page. The original editorial PNGs remain in `src/assets/editorial/`; the SpaceCharge source remains at `public/assets/img/spacecharge-editorial.png`. Live HTML headings supply the typography, with cobalt and terracotta artwork in the original halftone style. Each output has a genuine alpha channel and is saved beside the editorial sources as `spacecharge-cutout.png`, `the-next-experiment-cutout.png`, or `learning-the-dynamics-cutout.png`.

## spacecharge

Use case: background-extraction and precise-object-edit. The supplied SpaceCharge.jl poster is the EDIT TARGET. Create a transparent cutout of the existing charged particle bunch, computational mesh and electric field paths for layering behind live website typography. Remove ALL lettering: the large 'SpaceCharge.jl', the '3D space-charge fields / CPU + GPU' subtitle, and 'Ningdong Wang' signature. Reconstruct mesh lines where text interrupted them. Replace the neutral paper background, including between the grid lines and particles, with genuine alpha transparency. Preserve the exact existing blue computational mesh geometry, orange elongated particle bunch, curved blue electric-field paths and arrowheads, original ink colors, fine halftone grain, perspective, composition, portrait canvas and crop. Keep all colored ink marks and fine lines intact. No new elements, no scientific reinterpretation, no tint, recoloring, fade, glow, shadow or outline. No white/gray rectangle or baked checkerboard. Output only the original ink artwork with no words on real transparency.
