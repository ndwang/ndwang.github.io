LangChain-era pipeline vs modern ReAct

Task: a customer asks "My order hasn't arrived — where is it?"

A typical 2023 LangChain customer support agent made four separate LLM calls to handle one message. Each step was hardcoded by a developer into the smallest possible task — exact category names, exact field names, exact template variables — because models at the time weren't reliable enough to do multi-step reasoning, produce consistent structured output, and maintain tone all in one shot. Outputs were strictly typed so the next chain could consume them, which meant one unexpected string from the model cascaded into a crash downstream. The framework was compensating for model limitations, not productivity on top of them.

The same task in 2024 runs in a single generation. Tone is handled by one line in the system prompt — set once, applied throughout, no dedicated chain. Intent classification, field extraction, and response formatting happen inside the model's reasoning; they're not separate LLM calls. The only external step is the actual order lookup, because that genuinely needs live data. Everything the 2023 pipeline delegated to hand-coded stages is now a capability the model brings on its own.
