Agent Skills — progressive disclosure

Skills are modular folders loaded on demand. The alternative — stuffing everything in upfront — wastes most of the context window on irrelevant instructions.

Step 1 of 5

The skills library can hold dozens of capability folders — each with full instructions, scripts, and examples. None are loaded yet. The context window starts empty, waiting for a task.

The naive alternative: load all skills upfront on every call. With even a modest library this fills most of the context window with irrelevant instructions — the model is attending to pdf, pptx, and database instructions when someone just asked for a Word doc. Cost scales with library size, not task complexity. This is the problem progressive disclosure solves.

When a task arrives, only short one-line descriptions of each skill are in context — around 10 tokens each. The agent reads them to decide which skill to load. This is the first level of disclosure: tiny summaries rather than full instructions.

Only the relevant skill is loaded — its full instructions flow into the context window. Everything else stays on disk. The window stays lean regardless of how large the library grows.

The next task loads a completely different skill. The context window is roughly the same size as before. You can add a hundred skills to the library without making any individual request larger or more expensive. The bottleneck shifts from model intelligence to knowledge organisation.
